# How big must an atom be before its filling rule breaks?

Author: Michaël Perreault

An introduction, in plain language, to the research paper *Where the $n+l$ rule breaks in the Thomas-Fermi atom: certified zero-energy thresholds, Madelung order through $n+l=10$, and the first overlap at $n+l=11$* (concept DOI [10.5281/zenodo.24542256](https://doi.org/10.5281/zenodo.24542256)). The paper has the proofs. This note has the idea, and it says what the paper does and does not claim.
